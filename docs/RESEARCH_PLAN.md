## Next Mathematical Phase

1. Split the remaining 32 branches by deeper stabilizer orbits.
2. Seek exact dual certificates for the smallest residual subbranches.
3. Generate proof-producing SAT instances where compact dual certificates do
   not emerge.
4. Continue independent 16-word construction and exact repair searches.

## Acceptance Gates

- A new branch exclusion requires deterministic case generation, a retained
  exact certificate or checked proof log, independent replay, mutation tests,
  and an updated residual ledger.
- A 16-word construction requires direct exhaustive coverage checks by two
  independent implementations and a refreshed public-source audit.
- A global lower-bound claim requires checked exclusions covering every
  normalized size-at-most-16 branch.

## Kill Criteria

- A timeout is not an exclusion.
- A solver status without a checked certificate or proof log is not a
  theorem.
- A repeated near-cover score is not evidence of existence or impossibility.
- A local branch theorem does not change the global interval unless all
  remaining branches are closed.
